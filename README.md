# Sono & Conforto

O Sono & Conforto é um website desenvolvido para a disciplina de Programação Web Front-end, com a proposta de apresentar uma loja de colchões e produtos voltados à qualidade do sono.

O principal objetivo do projeto é oferecer uma experiência de navegação simples e intuitiva, permitindo que os visitantes conheçam diferentes modelos de colchões, suas dimensões, características e ofertas, facilitando a escolha de um produto adequado às suas necessidades.

Durante o desenvolvimento, busquei aplicar os conhecimentos adquiridos na disciplina, utilizando HTML, CSS e JavaScript para construir uma interface responsiva, visualmente agradável e funcional, com foco na organização do código e na experiência do usuário.

## Funcionalidades

O website possui diversas funcionalidades que permitem ao visitante conhecer os produtos disponíveis, navegar pelas páginas e interagir com o sistema de cadastro de usuários.

- **Catálogo de produtos:** apresentação dos diferentes modelos de colchões, com imagens, dimensões, características e ofertas.

- **Cadastro de usuários:** formulário para preenchimento de informações pessoais, com direcionamento para a página de login.

- **Área administrativa:** gerenciamento de usuários, permitindo realizar novos cadastros, pesquisar por nome ou e-mail, limpar os campos do formulário e excluir registros individualmente ou em conjunto.

- **Armazenamento local:** utilização do Local Storage para manter os registros cadastrados mesmo após a atualização da página.

- **Layout responsivo:** adaptação da interface para diferentes tamanhos de tela.

- **Currículo profissional:** acesso às informações acadêmicas e profissionais do desenvolvedor por meio de um link disponível no rodapé do website.

## Tecnologias utilizadas

Para o desenvolvimento do Sono & Conforto, utilizei tecnologias fundamentais do desenvolvimento web, buscando aplicar na prática os conhecimentos adquiridos durante a disciplina.

- **HTML5:** estruturação e organização do conteúdo das páginas.
- **CSS3:** desenvolvimento da identidade visual, estilização e adaptação do layout para diferentes dispositivos.
- **JavaScript:** implementação das funcionalidades e interações do website.
- **DOM:** manipulação dinâmica dos elementos das páginas.
- **Local Storage e JSON:** armazenamento e gerenciamento dos dados dos usuários.
- **Visual Studio Code:** ambiente de desenvolvimento do projeto.
- **GitHub:** hospedagem e organização do código-fonte.
- **GitHub Pages:** publicação e disponibilização do website na internet.

## Estrutura do projeto

Os arquivos foram organizados de acordo com suas respectivas responsabilidades, facilitando a compreensão, a manutenção e futuras melhorias no projeto.

```text
sono-conforto/
├── index.html
├── cadastro.html
├── login.html
├── admin.html
├── curriculo.html
├── css/
│   └── style.css
├── js/
│   ├── admin.js
│   └── cadastro.js
├── img/
├── CONTEXTO_PROJETO.md
└── README.md
```

- **index.html:** página principal e catálogo de produtos.
- **cadastro.html:** página de cadastro de usuários.
- **login.html:** página de login.
- **admin.html:** página de gerenciamento de usuários.
- **curriculo.html:** currículo profissional do desenvolvedor.
- **css/:** arquivos de estilização do website.
- **js/:** arquivos responsáveis pelas funcionalidades em JavaScript.
- **img/:** imagens e ícones utilizados no website.
- **CONTEXTO_PROJETO.md:** documentação técnica do projeto.
- **README.md:** apresentação e informações gerais do projeto.
